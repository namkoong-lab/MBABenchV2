OUTPUT FILENAME REQUIREMENT (MANDATORY):
You MUST create a file named exactly "solution.xlsx" in the workspace.
This is NOT optional and NOT configurable. Validation will REJECT any other filename.
Example: create_file(filename="solution.xlsx", worksheets=[...])

CRITICAL CIRCULAR REFERENCE PREVENTION:
- NEVER use = prefix for constants (use 19999 not =19999)
- NEVER use = prefix for text (use "Revenue" not ="Revenue")
- ONLY use = prefix for calculations with set_cell_formula tool
- ALWAYS check cell contents before referencing in formulas
- NEVER reference cells containing text in mathematical formulas
- NEVER create formulas where the cell is within its own range (e.g., B2: =SUM(B1:B5))

FORMULA TOOL USAGE (CRITICAL):
- ALWAYS use set_cell_formula for ANY formula (no exceptions)
- NEVER use edit_cells for formulas - they will be stored as text and fail validation
- edit_cells is ONLY for text labels and numeric constants, NOT formulas
- For multiple formulas: use actions array with multiple set_cell_formula calls
Example WRONG: edit_cells([{"cell": "B2", "value": "=SUM(A1:A10)"}])
Example RIGHT: set_cell_formula({"cell": "B2", "formula": "SUM(A1:A10)"})

STEP 4 - VALIDATION REQUIREMENTS:

STEP 5 - SUMMARY & OUTPUT PRESENTATION:
Structure answer sheets clearly for evaluation:

For complex WSP tasks, create a summary area:

STEP 6 - PROFESSIONAL FORMATTING:
After all calculations are complete, apply professional formatting:

1. Header formatting: Apply dark blue fill with white bold font to all header rows
   format_cells(filename, sheet, "A1:Z1", fill={"color": "002060"}, font={"color": "FFFFFF", "bold": true})

2. Color-code inputs: Blue font on all hardcoded input values
   format_cells(filename, "Assumptions", "B2:B50", font={"color": "0000FF"})

3. Number formats: Apply appropriate number_format to all data cells
   - Currency columns: "$#,##0_);($#,##0)"
   - Percentage columns: "0.00%"
   - Integer columns: "#,##0"

4. Column widths: Set labels wide, data columns standard
   set_column_width(filename, sheet, {"A": 35, "B:Z": 15})

5. Freeze panes: Lock headers and labels on sheets with many rows
   freeze_panes(filename, sheet, "B2")

6. Borders: Thin under headers, double under totals
   format_cells(filename, sheet, header_range, border={"style": "thin", "edges": ["bottom"]})
   format_cells(filename, sheet, total_range, border={"style": "double", "edges": ["bottom"]})

7. Alignment: Right-align numbers, center headers
   format_cells(filename, sheet, data_range, alignment={"horizontal": "right"})
   format_cells(filename, sheet, header_range, alignment={"horizontal": "center"})
