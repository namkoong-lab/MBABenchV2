## Rule as implemented

**Fail** when the delivered workbook references another workbook, or keeps a live link to
an external data source, anywhere:

| place | what counts |
|---|---|
| declared external links | every `<externalReference>` in workbook.xml (its externalLink part: `externalBook`, `ddeLink` or `oleLink`), **whether or not any formula uses it**. The description says how many formula sites use it. Excel Online's bare own-sheet targets (corpus 1375: links "to" `DCF` and `Checks`) count |
| cell formulas (worksheets, macro sheets; shared children of a flagged master) | any reference operand or name call into another workbook: `[1]Sheet!A1`, `'[1]My Sheet'!A1`, `[1]!Name`, `[1]!MyFn(..)`, `[Book.xlsx]Sheet!A1` (openpyxl-style, no link part), `'C:\dir\[Book.xlsx]Sheet'!A1`, `'C:\dir\Book.xlsx'!Name`, `Book.xlsx!Name` when no sheet is called `Book.xlsx` |
| defined names | the same, used or not, hidden or not (toy T2: an unused visible name). A name whose `localSheetId` names no sheet still counts (its usage note then says its use cannot be traced) |
| conditional formats, data validations | main and x14 (`<xm:f>`) formulas (toy T4: x14 list DV), incl. colour-scale / data-bar / icon-set thresholds (`<cfvo val="'[Other.xlsx]S'!$A$1">`) |
| charts | series/category/title formulas (`<c:f>`), and a chart part's external (non-hyperlink) relationship (external chart data) |
| sparklines, shape text links, form controls | sparkline data/date ranges; `textlink` of drawing shapes; `fmlaLink`/`fmlaRange`/`fmlaTxbx`/`fmlaGroup` of `xl/ctrlProps` parts |
| pivot caches | a cache whose worksheet source (or any relationship of its definition part) points outside the package |
| data connections (`xl/connections.xml`) | `COUNT_DATA_CONNECTIONS = True`: a non-deleted ODBC/OLEDB/text/web connection fails ("the file is self-contained" in the rubric's good criterion). Not counted: `deleted="1"`, the workbook's own Data Model (`ThisWorkbookDataModel`, `$Embedded$`), worksheet connections (`WorksheetConnection_*`, `rangePr`) |

**Not links** (handoff: "Web hyperlinks and file names in text are not links"): cell or
shape hyperlinks (web or to another file; hyperlinks to spreadsheet files are counted in
`stats.hyperlinks_to_files_not_counted`, `COUNT_FILE_HYPERLINKS = False`),
`HYPERLINK("C:\x\Other.xlsx",...)` (a string), text naming a file (`Q3_comps.xlsx`), string
literals (`"[Book.xlsx]Sheet1!A1"`, `"[Act/360]Nominal"`), `[0]!Name` (this workbook),
externalLink parts in the zip that workbook.xml does not reference
(`stats.orphan_external_link_parts`; Excel ignores them).

Pre-filter (`may_be_external`): with string literals masked, every external form contains
`[`, a backslash, `://`, or a file extension right before `!`; texts without any of them are
not parsed. Parsing is `formula.parse(...).external_references(sheet_names=...)` plus
qualified function calls.

**Exception** ("unless required by the case context"): `task_meta["requires_external_links"]`
(passed to `grade(..., task_meta=...)`). `True`: every finding is moved to stats
(`links_found_but_required`, `n_links_found_but_required`) and the check passes. Absent,
`None` or `False`: not required. Any other value raises `GradingError`.

**No guess** (raises `GradingError`):
* an `<externalReference>` whose externalLink part is missing/unreadable;
* Power Query (a Mashup OLEDB connection, `$Workbook$`, or a `DataMashup` customXml item)
  when nothing else fails the file: its sources live in M code that is not decoded. When
  something else already fails the file, the queries are listed in `stats.power_query`.

### Mistakes

* `External link [n]` per declared link (first), then `Name Manager: <name>`, then
  `'<sheet>'` (bare sheet name) for charts / shapes / form controls on that sheet,
  `Pivot cache: <part>`, `Data connection: <name>`;
* `'Sheet'!<range>` - cell formulas grouped into rectangles per sheet and per set of target
  workbooks;
* `'Sheet'!<sqref>` per CF block / DV / sparkline host that reads another workbook.

Stats: `n_formula_cells`, `n_formula_texts`, `n_flagged_cells`, `n_external_links`,
`n_names`, `n_names_flagged`, `n_cf_rules`, `n_data_validations`,
`requires_external_links`, `orphan_external_link_parts`, `hyperlinks_to_files_not_counted`,
`hyperlink_examples`, `power_query`, `deleted_connections`, `internal_connections`.

## Known limits

* Power Query M code is not decoded (raises when it would decide the verdict).
* VML (legacy) form controls (`x:FmlaLink` in vmlDrawing parts), ActiveX, OLE objects other
  than through their externalLink part, query tables and VBA are not read.
* Link identity is not compared with any starting file (whole-workbook rule): an inherited
  link fails like a new one.
* Malformed formula text raises (`FormulaError`) only when the pre-filter sees a possible
  external form in it; otherwise it is not parsed and does not raise.
