## Rule as implemented

**What 51 judges.** Every formula cell of the delivered workbook whose class is **EXTERNAL** must have a font in the **red** family. All sheets count, hidden ones included, and nothing is exempt as inherited. HYPERLINK navigation cells are ignored (ruling 2026-10-03), and EXTERNAL cells are judged by 51 only (49 no longer also judges them).

**The red family** covers hue < 15° or ≥ 340°, s ≥ 0.5, v ≥ 0.35. That includes FF0000, C00000, C0504D, 9C0006 and 800000, but not FF6600 or FF99CC.

**What makes a cell EXTERNAL.** Its formula reads another workbook anywhere in the formula, in any of these ways:
- a book-index reference, as Excel stores it: `[1]Prices!$C$5`, `'[1]Annual Summary'!$H$41`. The index is not checked against the externalLink parts, so an orphan `[3]` still counts;
- a path or file form: `'C:\p\[Book.xlsx]S'!A1`, or `'C:\p\Book.xlsx'!Name`;
- an external name: `[1]!Rate`;
- a qualifier that looks like a file (`Other.xlsx!Rate`) when no sheet of the workbook has that name;
- a defined name whose definition, followed transitively, reads another workbook;
- a literal `INDIRECT("'[Book.xlsx]S'!A1")`.

**Pure pointers and calculations.** A pure pointer to another workbook is EXTERNAL (51), not POINTER (50). An external reference inside a calculation still counts (`=[1]Rates!$B$2*C25`).

**Spills and arrays.** Spill / array members take their anchor's class; each member's own font colour is judged.

**Satisfied by default.** When no formula cell is EXTERNAL and non-red, 51 passes. That includes workbooks with no external reference, and workbooks with no formula at all.

**What 51 does not judge.** External references that live only in defined names, charts, data validation or conditional formats are not cells; they are check 95's topic.

**Optimisation.** Red cells are never classified. A non-red formula is parsed only if a conservative pre-filter (`Classifier.may_read_other_book`) says it could be external. The pre-filter looks for any of these:
- a `[` outside string literals;
- a quoted path qualifier (`\` or `/` inside `'…'!`), or a workbook extension right before `!`;
- an identifier that names a defined name reaching another workbook.

String literals are scanned too when the formula calls INDIRECT. A defined name whose `localSheetId` names no sheet (unknown scope) counts only if one of its possible definitions (it, or a same-named definition it might shadow) may read another workbook.

**Raise only where needed.** A font colour that cannot be resolved (core `styles.UnknownColour`; since 2026-10-04 also an invalid custom `<indexedColors>` entry, an rgb of other than 6 or 8 hex digits or an invalid tint, see 49.md) raises only on a cell that reads another workbook; on any other formula cell it cannot change 51's verdict, so a workbook with no external reference still passes "by default" (stats `unresolved_colour_cells_not_needing_it`). A defined name with an unknown scope raises only when the cell's class is not already EXTERNAL and one of the name's possible definitions may read another workbook; a cell that certainly reads another workbook otherwise (directly, or through a normal defined name such as `=GoodExt+BadExt`) is decided (it fails unless red; 2026-10-04, R1). A structured reference or bare table name whose table is not defined, or whose table parts cannot be read, never raises here: a table without a `[n]!` qualifier is this workbook's, so which sheet it sits on cannot change 51's verdict (`ColourCheck.sheets_needed` is False for 51; stats `table_lookup_failures_not_needing_it`; 2026-10-04, R2). Malformed formula text still raises when the pre-filter let it through and the cell is not red.

**Mistakes.** One per rectangle of offending cells, per sheet and per exact colour. Each says "formula reading another workbook in {colour} font; external links must be red" and gives an example formula. Stats list the externalLink parts (index, kind, target).

## Edge-case decisions

- **Syntactic, not resolved**: a `[n]` reference is external whether or not externalLink part n exists or points to a real file. The report's "orphan index" case is therefore a fail when the cell is not red.
- **Excel Online own-sheet artefact** (corpus attempt 1375): `Summary!B27:B38` hold `=[1]DCF!D12`, and the externalLink part's target names the workbook's own sheets. These count as external, so the 12 cells (black and green) fail.
- **Computed INDIRECT** is not treated as reading another workbook, because INDIRECT cannot read a closed workbook. A literal external INDIRECT address counts.
- **Strings**: `IF(A1,"[1]Prices!A1",0)` is not a reference.

## Known limits

- DDE / OLE links (`=Excel|'Sheet'!A1`) are not modelled by the formula tokenizer.
- See 49.md for the shared limits.
