Tests: `detchecks/tests/test_checks_formulascan.py` (`test_87_*`, `test_95_87_drawings`,

## Rule as implemented

**Fail** when any formula site holds a whole-column or whole-row reference, i.e. an operand
that `detchecks.core.formula` classifies as `whole_column` or `whole_row`:
`A:A`, `$A:$C`, `Sheet!A:A`, `'My Sheet'!$B:$B`, `Jan:Dec!A:A` (3-D), `[1]Data!A:A`
(another workbook), `1:1`, `$17:$17`, `1:10`, and the A1 spellings Excel itself shows as
whole columns/rows (`A1:A1048576`, `A1:XFD1`). Counters and endpoints are not exempt:
`ROW(1:10)`, `COLUMNS($E:E)`, `INDEX($A:$A,20)` all fail.

Formula sites (whole delivered workbook, hidden sheets included):

| site | counted |
|---|---|
| cell formulas on worksheets and macro sheets (normal, array, shared; every child of a flagged master is flagged, since a whole column stays whole when copied; a child of an unflagged master whose bounded range has one end absolute at the sheet edge is re-classified from its own shifted text: master `B1 =SUM($A$1:A1048575)` makes the copy `B2 =SUM($A$1:A1048576)` = column A, which fails) | yes |
| defined names | a name whose own definition holds a whole reference counts **when a formula site uses it**, directly or through other names (visible or hidden, built-in or not). Uses: cell, CF and DV formulas (incl. a literal `INDIRECT("Name")`), chart series, sparklines, shape text links, form controls (`xl/ctrlProps` input ranges / cell links, e.g. a combo box fed by `AllItems = Lists!$A:$A`), pivot caches built on the name; a built-in name is used whether a formula writes `Print_Area` or `_xlnm.Print_Area`. The tally stops parsing after 3 uses ("used by at least N"). A name whose `localSheetId` names no sheet is left out of name resolution; a flagged name whose use depends on it (its own scope, or a name on the chain to it) raises only when nothing else fails for certain (no cell, CF, DV or other counted name): otherwise it is listed in `stats.whole_ref_names_use_undecidable_not_counted` and the verdict stands. Unused ones are listed in `stats.whole_ref_names_unused_not_counted` (`COUNT_UNUSED_NAMES = False`): above all Excel's print settings (`_xlnm.Print_Titles` can only be whole rows/columns; GPT-6 writes dynamic print areas `$B$1:INDEX($M:$M,n)`) |
| conditional-format and data-validation formulas, main and x14 (`COUNT_CF_DV = True`), incl. colour-scale / data-bar / icon-set thresholds (`<cfvo val="MAX($A:$A)">`, x14 `<xm:f>`) | yes: they are formulas Excel evaluates; `COUNTIF($A:$A,A1)>1` in CF is the classic case |
| chart series, sparklines, pivot-cache sources | no: they are data sources, not formulas (report §4b) |

Never counted (they are not whole references): trimmed ranges (`A:.A`, `A.:A`,
`_xlfn._TRO_TRAILING(A:A)`, `TRIMRANGE((A:A))` - the rubric's remedy; counted in
`stats.trimmed_ranges_seen`), table references (`Table1[Val]`), spill references (`A1#`,
`ANCHORARRAY`), `Name1:Name2`, text in string literals (`"Mix "&"1:2"`,
`TEXT(A1/24,"hh:mm")`, `INDIRECT("A:A")`) and text cells ("Ratio 1:1", "Split A:B").

**Sheet-edge ranges** that are not whole (`A2:A1048576`, `B7:XFD7`) are **not** counted
(task instruction); they are counted in `stats.sheet_edge_ranges_not_counted` with up to
five examples (per distinct formula text; a shared group counts once).

A cell that uses a whole-column **name** is not a separate mistake; the name is, and its
description lists the formula sites that use it (directly or through other names).

Pre-filter: `formula.quick_may_have_whole_refs` (conservative; string literals masked).
Only texts it accepts are parsed.

### Mistakes

* `Name Manager: <name>` per flagged name, first.
* `'Sheet'!<range>` - flagged cells grouped into rectangles per sheet and per kind
  ("whole-column", "whole-row", or both), with up to three example references from the
  top-left formula.
* `'Sheet'!<sqref>` - one per CF block / DV with a whole reference.

A name's definition is shown once with '=' even when the writer stored it with a leading
'=' (`(=S!$A:$A)`, not `(==S!$A:$A)`).

Stats: `n_formula_cells`, `n_formula_texts`, `n_flagged_cells`, `n_names`,

## Known limits

* Chart/sparkline/pivot sources are not scanned for this check (policy above); they do count
  as *uses* of a name.
* VML (legacy) form-control ranges are not read.
* A shared-formula copy pushed off the grid becomes `#REF!` in Excel; the check still
  counts it as a copy of its flagged master (such a group already holds a whole reference,
  so the verdict does not change; only the flagged range may be one cell too large).
* Malformed formula text raises (`FormulaError`) only when the pre-filter sees a possible
  whole reference in it (e.g. `SUM(A:A` with no closing parenthesis); otherwise it is not
  parsed and does not raise.
